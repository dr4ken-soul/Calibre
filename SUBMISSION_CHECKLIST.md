# Calibre Submission Checklist

## Required by the hackathon

- [ ] Working prototype deployed on the required testnet
- [ ] DreamDEX Event Contracts integration is visible
- [ ] GitHub repository is public or accessible to judges
- [ ] Two to three minute demo video is recorded
- [ ] DoraHacks submission is complete
- [ ] Project description explains the problem, solution, product, demonstration, and future vision
- [ ] Testnet setup instructions are included
- [ ] Environment variables are documented without real secrets

## Technical verification

- [ ] Live market loads
- [ ] Market ID is visible
- [ ] Lifecycle status is read from the protocol
- [ ] Order-book data has a source timestamp
- [ ] Probability audit uses validated inputs
- [ ] No-trade path works
- [ ] Critical guards can block an order
- [ ] User explicitly approves the transaction
- [ ] Pending state works
- [ ] Confirmed state is receipt verified
- [ ] Rejected wallet state works
- [ ] Failed transaction state works
- [ ] Settlement state is read from chain
- [ ] Audit, trade, and settlement are linked by market ID and audit ID
- [ ] No fabricated performance data appears

## Experience verification

- [ ] Hero follows FRONTEND_SPEC.md
- [ ] Sticky section indicator works
- [ ] Canvas pauses offscreen
- [ ] SVG state morph has a reduced-motion fallback
- [ ] Keyboard navigation works
- [ ] Focus states are visible
- [ ] Touch targets meet the minimum size
- [ ] Canvas has a text summary
- [ ] Stale, unavailable, empty, and error states are understandable
- [ ] No purple or blue AI glow appears
- [ ] No hardcoded logo or brand symbol appears
- [ ] No direct colour literals appear in JSX
- [ ] No em dashes appear in user-facing copy or documentation

## Demo recording

- [ ] Clean browser profile
- [ ] Correct testnet selected
- [ ] One passing market prepared
- [ ] One no-trade market prepared
- [ ] No secrets visible
- [ ] Market ID visible during the explanation
- [ ] Source timestamp visible
- [ ] Wallet approval shown
- [ ] Transaction state shown
- [ ] Settlement or pending settlement shown honestly
- [ ] Video is between two and three minutes
- [ ] Backup recording with fallback data is available

## Optional materials

- [ ] Presentation deck
- [ ] DreamDEX SDK feedback report
- [ ] Optional X post
- [ ] Architecture diagram
- [ ] Short product walkthrough
